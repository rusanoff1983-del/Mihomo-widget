# Mihomo Widget v1.0.0

## Русский

Первый выпуск виджета Mihomo для Windows. Он подключается к вашему контроллеру Mihomo и позволяет переключать прокси, просматривать подписки и измерять задержку прямо с рабочего стола.

- 16 тем оформления и системная тема; интерфейс на русском и английском.
- Трей с иконкой кота M, быстрые действия и глобальная клавиша `Ctrl+Shift+Space`.
- Прозрачность, автозагрузка, закрепление поверх окон, прилипание к краям, запоминание положения и режим клика насквозь.
- Подписанные пакеты для будущих обновлений через GitHub Releases.

**Установка:** скачайте `Mihomo-Widget_1.0.0_x64-setup.exe` или MSI-файл ниже. При первом запуске укажите адрес контроллера и API secret в настройках. Эти данные не включены в сборку.

## English

The first Windows release of Mihomo Widget. Connect it to your Mihomo controller to switch proxies, view subscriptions, and measure latency from your desktop.

- 16 themes plus a system theme; Russian and English interface.
- Cat M tray icon, quick actions, and the `Ctrl+Shift+Space` global shortcut.
- Opacity, autostart, always on top, edge snapping, saved position, and click-through mode.
- Signed packages for future updates through GitHub Releases.

**Install:** download `Mihomo-Widget_1.0.0_x64-setup.exe` or the MSI file below. Enter your controller address and API secret in Settings on first launch. Neither is included in the build.
