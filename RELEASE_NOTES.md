# Mihomo Widget v1.0.1

## Русский

Первый выпуск установщика виджета Mihomo для Windows. Исправлено переключение серверов: выбор теперь отправляется в Mihomo и отмечается успешным только после подтверждения от контроллера. Исходный вариант 1.0.0 ошибочно менял выделение карточки, не отправив команду.

- 16 тем оформления и системная тема; интерфейс на русском и английском.
- Трей с иконкой кота M, быстрые действия и глобальная клавиша `Ctrl+Shift+Space`.
- Прозрачность, автозагрузка, закрепление поверх окон, прилипание к краям, запоминание положения и режим клика насквозь.
- Подписанные пакеты для будущих обновлений через GitHub Releases.

**Установка:** скачайте `Mihomo-Widget_1.0.1_x64-setup.exe` или MSI-файл ниже. При первом запуске укажите адрес контроллера и API secret в настройках. Эти данные не включены в сборку.

## English

The first Windows installer release of Mihomo Widget. Server switching is fixed: the widget now sends the selection to Mihomo and marks it successful only after reading it back from the controller. The original 1.0.0 source changed the card highlight without sending the command.

- 16 themes plus a system theme; Russian and English interface.
- Cat M tray icon, quick actions, and the `Ctrl+Shift+Space` global shortcut.
- Opacity, autostart, always on top, edge snapping, saved position, and click-through mode.
- Signed packages for future updates through GitHub Releases.

**Install:** download `Mihomo-Widget_1.0.1_x64-setup.exe` or the MSI file below. Enter your controller address and API secret in Settings on first launch. Neither is included in the build.
